The panel has a unique `(symbol, timestamp)` index with timezone-aware timestamps, finite numeric feature columns and label, and the four timezone-aware columns `available_at`, `label_end`, `position_end` and `label_available_at`. 2. Call `campaign_registry.register(path, first=..., dataset=..., common=..., incumbent=..., baseline=..., challengers=..., routing=..., seed=...)` before the first scheduled open. The optional `clock` is injectable for tests. The CLI `experiment_cli.py --db PATH register FILE.json` takes the same public inputs with `first` encoded as an ISO date. Set `common` to the exact fields in the table. A policy spec contains `source`, `guard`, `parameters` and `weights`. Candidate proposals contain `spec`, `parent=digest(incumbent)`, `hypothesis` and `feature`. The baseline is mandatory and an absent incumbent is `None`. For parameterized campaigns record the development-only behavior probes for all required policies and ablations before enrolling. The registry derives the comparison family and scenarios. Supply the full routing manifest from Agent 2.
3. Store the returned campaign ID and load `frozen_campaign(path, id)` for the calendar and complete manifest. A matching registration retry returns the original ID. A different registration spends a new UTC-year slot, up to the global cap of 12. Keep append-only receipts in the same ledger. The close and verification deadlines come from the manifest. Agent 3 should surface missed sessions and verification gaps as inconclusive and preserve the original close schedule.

## Agent 1. Produce and verify marked panels

Read the persisted manifest and use the registered calendar prefix through the requested day as input to `marked_session.replay_marked_session`. Every `SessionTape` uses the same ordered quotes for all registered arms and scenarios. Supply the evaluated decision stream for every frozen specification and parameter neighbor, including explicitly empty streams, keyed by `digest(spec)`. Supply the benchmark opening and closing observations and regime changes. Carry forward Decimal cash, marked peak and loss latches across days. The quote adapter and its field semantics are documented in Agent 1's [portfolio contract](https://github.com/asadtft789-netizen/pc_ai_trading/blob/6f55c879b3ef05d1d947a8c520e2c87c5da39843/coordination/PORTFOLIO_CONTRACT.md).

The registry accepts the whole panel with `record_session(path, id, day, payload)`. The payload has `origin="prospective_shadow"`, `event_digest`, `benchmark_return`, `portfolios`, `scenarios`, `replay_inputs` and `regime_seconds`. Use UTC integer seconds for marks and episode endpoints and finite dollar amounts for net equity and gross traded notional. For each row provide the common mark grid, closed economic episodes with strategy-independent trace digests, and net P&L attributed by symbol and regime. Flat zero-trade sessions carry previous equity forward. Regime seconds sum to the session duration. Write within the 120 seconds from the registered close. The registry deduplicates exact receipt retries and rejects conflicting replacements.

Use an independent implementation and the same original sealed input artifacts to generate `{day: digest(panel)}` for **every** registered session. Call `record_verification` after loading all receipts, within the frozen verification deadline. Provide the registered producer and verifier identities, `data_quality`, `safety` and `assumptions` receipts of the form `{"passed": bool, "artifact": sha256}`, and the calibration record ID for the exact registered design, family size, seed, implementation and effect. Then `close_campaign` persists the decision. An early manual close with missing evidence makes the deficiency final. The scheduled expiry path closes unresolved campaigns after the verification deadline. Report the observed evidence and the F16 hold separately.

**Remaining producer boundary.** The adapter includes the actual policy in the event digest, but `replay_inputs` builds artifact bindings from the supplied manifest. The collector must resolve the registered code, risk, execution, and cost artifacts and check the actual runtime policy against them before writing. It must also verify that all previously sealed source segments in the tape prefix are identical on every later replay. A digest of a new prefix alone cannot prove that an earlier segment was preserved. Retain canonical quote ordering, immutable manifests per day, and independently verifiable linkage between the earlier receipt and its source segment. The independent verifier must verify those bindings, source timestamps and artifacts itself. The tested adapter uses synthetic quotes and modeled costs. Broker actuals and fee evidence require their own source.
